# MyFilmTV v0.4 — Remote-friendly browsing

## Added

- Three simple, D-pad accessible filters on category pages: genre, release year and sort.
- Genre/year/sort work on the **currently cached** catalog; as additional pages are fetched, matching results are added. This is **not** a globally complete server-side query. Scores and hits come from each individual MacCMS provider and are not comparable across providers.
- Detail dialog now shows available metadata: genre, region, director, cast, provider score, status and synopsis, followed by selectable playback lines/episodes.
- Added parsing and persistence of `vod_class`, `vod_area`, `vod_actor`, `vod_director`, `vod_score`, `vod_time`, `vod_hits`, `vod_remarks` in existing SQLite payloads. No database migration required (JSON payload extension).
- `versionCode=4`, `versionName=0.4`.

## TV navigation

Category -> OK on any of three filter buttons -> up/down in single-choice dialog -> OK -> Back closes. Press Down to enter poster grid. Movie detail -> up/down episode list -> OK to play.

## Known limits

- Filter/sort currently acts on the locally cached set, not remote server-wide search. Results expand as pages load. No fabricated full-library sorting.
- Missing metadata stays blank. Popularity (`vod_hits`) is per provider, not a normalized ranking.
- Large catalogs still use native GridLayout; RecyclerView is advised for future performance.
- Build and physical-TV playback must be validated with GitHub Actions and Android TV.

## How to update

Upload this project's files to the existing repository root, preserving `.github/workflows/build-apk.yml`, and commit. GitHub Actions produces `MyFilmTV.apk`. The current workflow uses ephemeral debug signing; you may need to uninstall a previous debug APK if Android reports INSTALL_FAILED_UPDATE_INCOMPATIBLE, which clears local application settings.
