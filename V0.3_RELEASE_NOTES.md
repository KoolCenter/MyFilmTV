# MyFilmTV v0.3 — staged catalog preview

- Preserves the existing `sources.json` schema (`schemaVersion: 1`) and Android package ID.
- Adds a local SQLite catalog for metadata, episode/play-line information and source-specific pagination cursors.
- Uses cached movies on the home screen, with limited background prefetch (up to two pages per category/source/type ID).
- Browsing a specific category requests additional pages and appends new cards; scrolling near the bottom triggers further loads.
- Uses each source's category hierarchy to prefer the parent type where present.
- Captures video playback position on pause/exit for a Continue Watching home lane.
- Keeps D-pad focusable posters and menu actions.

## Important implementation boundaries

- First-run cache is empty and remote sources may take time to respond. Catalog size depends on each upstream API and its pagination.
- New results appear incrementally; only a limited number of background pages are fetched while idle. The app does not attempt to crawl the full library indefinitely in the background.
- Search remains a first-page query per source; full search pagination is future work.
- The simple native GridLayout is not virtualized. Very large libraries can cause UI performance degradation: a recycled TV-focused grid is recommended before large-scale use.
- Movie deduplication uses name + year; there may be false matches or misses. Different sources may not share stable identifiers.
- A category depends on MacCMS type mappings and each upstream source's classification quality. Parent categories may not be served recursively by all providers.
- Debug APK builds are not guaranteed to share the same signature. Uninstall may be required until a persistent signing key is configured. Uninstall removes local catalog/history/settings.
- This source has not been compiled or run against an Android emulator in this environment. Verify compilation in GitHub Actions and run an emulator/TV smoke test before relying on it.
